Firefox keyboard shortcuts

  1. Open Firefox’s menu and choose Add-ons and themes, or type about:addons into a new tab.
  2. Select Extensions, then the gear menu and Manage Extension Shortcuts.
  3. Find Incremento Companion and set the shortcuts you want.

Keep Firefox focused when using capture shortcuts. Firefox does not support global extension shortcuts outside the browser.

If a shortcut is already used by Firefox or another extension, choose a different combination. You can also use Companion’s toolbar popup or the page’s right-click menu.
